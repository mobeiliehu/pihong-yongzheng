## 批红 · 雍正十三年

一款以雍正朝十三载政务为核心的**批红决策游戏**。单文件网页，双击 `index.html` 即可离线游玩，无任何外部依赖。

> 「奏事者三十三道，批红者一人。十三年后，是非只在朕心。」

## 玩法

- **33 道主奏折**，逐年覆盖雍正元年（1723）至十三年（1735），每折附真实年月、具奏人官衔与史料依据。
- **密折抉择**：每折都附带一封密报。查阅则得隐情、解锁「知情方略」选项，但**明察 +3、猜忌 +3**；封还不阅则**明察 −1、猜忌 −2**，且不得见知情方略。抉择代价在界面上以代价表列明。
- **支线事件**：14 组按史实年月锚定的邸报事件（蝗灾、劾年羹尧、宗室请安、摊丁士绅呈诉、直隶抗差、苗疆动乱……）+ 6 类随机灾异池。
- **数值与仪表**：国库 / 民心 / 官风 / 皇权 / 军力 + 国政大业（火耗归公、摊丁入亩、改土归流）+ 朝局取向（严刻−宽仁、吏治清、民怨）+ 圣心二端（明察、猜忌）+ 八位重臣人心。
- **10 种结局**，含「酷吏之治」「宽仁之君」「权臣之祸」「多疑之君」「闭目之君」等细分走向。

## 安装为 App（PWA）

- **Android / 桌面 Chrome、Edge**：地址栏右侧的安装图标，或菜单 →「安装应用」。
- **iPhone / iPad（Safari）**：点底部「分享」→「添加到主屏幕」。
- **macOS Safari**：文件 →「添加到程序坞」。
- 页面右下角也内置了「安装为 App」按钮与对应提示（iOS 会直接给出操作指引）。

安装后为独立窗口运行，无浏览器地址栏，断网可玩。

## 喵喵过街 · 手机版

Three.js 打造的小猫过街游戏（单文件 7.6 MB，内嵌 three.js 与中英文字体，无任何外部请求）。同一套 PWA 机制：安装后全屏运行、离线可玩。

## 目录结构

```
index.html                # 批红·雍正十三年（单文件，可直接运行）
manifest.webmanifest      # 根站 PWA 清单（批红）
sw.js                     # 根站 Service Worker（离线缓存）
icons/                    # 批红图标（192/512/maskable/1024 + apple-touch-icon）
miao/
  index.html              # 喵喵过街 · 手机版（单文件）
  manifest.webmanifest    # 喵喵 PWA 清单
  sw.js                   # 喵喵 Service Worker
  icons/                  # 喵喵图标
src/part1.html            # 页面骨架与样式
src/p2.js … p6.js         # 奏折数据、支线事件库、游戏逻辑
docs/                     # 设计说明书（docx / pdf）
```

`src/` 为可维护源码，发布版由以下顺序拼接而成：

```bash
cat src/part1.html src/p2.js src/p3.js src/p4.js src/p5_events.js src/p6.js > index.html
printf '\n</script>\n</body>\n</html>\n' >> index.html
```

## 史实说明

奏折内容依据雍正朝实录、清史稿相关记载撰写，涉及具体人名、官衔、地名、钱粮数目与制度名目（火耗归公、摊丁入亩、改土归流、隆宗门内军机房、廷寄、养廉银等）。已知史实修订清单见《设计说明书》第九章。
